# 부팅(Bu-ting)

부산 지역 특화 여행 계획 웹 서비스입니다. 지역/장소 탐색, 여행 일정 생성 및 관리, 정보 공유 채팅,
예산·기록 관리 등 부산 여행에 필요한 기능을 다국어로 제공합니다.

## 기술 스택

| 영역            | 기술                            |
| --------------- | ------------------------------- |
| 프레임워크      | Next.js (App Router)            |
| 언어            | TypeScript                      |
| 스타일          | Tailwind CSS                    |
| UI 컴포넌트     | shadcn/ui                       |
| 서버 상태       | TanStack Query                  |
| 클라이언트 상태 | Zustand                         |
| 다국어(i18n)    | next-intl (`[locale]` 세그먼트) |
