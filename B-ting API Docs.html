Auth

Authentication APIs

클라이언트가 Google/Naver/Kakao SDK로 SSO 로그인 후 받은 provider token을 백엔드로 전달합니다. Google/Naver/Kakao는 provider token 또는 authorization code를 전달할 수 있습니다. 백엔드는 provider token을 검증하고, 기존 회원 조회/연결 또는 신규 회원 생성을 수행한 뒤 B-TING 전용 opaque access token을 발급합니다. Swagger 상단 Authorize로 기존 B-TING opaque token을 인증해두면, 같은 사용자이고 만료 전인 경우 기존 토큰을 재사용합니다. 기존 토큰이 없거나 만료/폐기/다른 사용자 토큰이면 새 opaque token을 발급합니다.
